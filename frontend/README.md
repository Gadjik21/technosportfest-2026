# Фронтенд

React + TypeScript + Vite. `npm ci` устанавливает закреплённые версии, `npm run dev` запускает сайт на `http://localhost:5173`, `npm run build` генерирует API-типы, проверяет TypeScript и собирает SPA. `npm test` проверяет основной путь с подменённым API. Production-образ Nginx находится в `Dockerfile`; `docker compose up --build` отдаёт сайт на `http://localhost:8080`.

`src/api.ts` — общий клиент с типами схем из OpenAPI. Он работает с `/api/v1` на том же origin; Vite и Nginx проксируют запросы в FastAPI. `HttpOnly` JWT cookie отправляется браузером, JavaScript не читает токен. На старте вызывается `GET /auth/me`; `401` означает гостя, `403` и `409` показываются пользователю, поля ошибки `422` выводятся рядом с сообщением. Типы обновляются через `npm run types:api` из `../contracts/openapi.json`.

Готовы публичные страницы соревнований, рейтинга, новостей и документов, кабинет спортсмена, профиль, заявки, результаты, а также кабинет организатора с созданием соревнований, черновиками результатов, публикацией и контентом. Макет послужил визуальным ориентиром; функции вне OpenAPI MVP не добавлялись.
