# Ручная проверка MVP — 25 сентября 2026

Проверено в браузере Codex на локальных FastAPI и Vite. Применены миграции `0001_auth`–`0004_competitions` к отдельной тестовой SQLite-базе; использовались вымышленные спортсмен и организатор. Проверка прошла на мобильной ширине браузера и на 1440 × 900.

| Сценарий | Результат |
|---|---|
| Неверный вход, переход вход → регистрация, регистрация спортсмена, выход и повторный вход | Пройдено; ошибка входа очищается при смене формы |
| Профиль: образование, населённый пункт, дисциплина; перезагрузка страницы | Пройдено, данные сохраняются |
| Создание и редактирование черновика соревнования, список по статусу | Пройдено; изменения остаются после перезагрузки |
| Публикация соревнования и отмена в окне подтверждения | Пройдено |
| Публичный каталог и карточка, возврат к ней после входа, заявка | Пройдено; повторная заявка не предлагается после перезагрузки |
| Список участников, черновик результата, отмена и подтверждение публикации | Пройдено; соревнование становится `completed`, результат получает 100 очков |
| Публичные результаты, общий и личный рейтинг, фильтр по дисциплине, кабинет и история спортсмена | Пройдено; место 1 и 100 очков видны во всех экранах |
| Новости: создание, правка, публичная карточка | Пройдено |
| Документы: HTTPS-ссылка, правка, публичный список и фильтр категории | Пройдено |
| Запрет организаторского кабинета спортсмену; пустые состояния и консоль браузера | Пройдено; ошибок в консоли нет |

Для проверки ручного сценария исправлены доступ к профилю и выходу на мобильном экране, возврат к карточке после входа, очистка ошибки при смене формы, подтверждения публикации и проверка email в CLI создания организатора.

**Ограничения проверки:** Docker daemon на этом компьютере недоступен, поэтому полный ручной сценарий через контейнеры Nginx и PostgreSQL не пройден. CI отдельно запускает `make up` с PostgreSQL и Nginx и проверяет доступность API и сайта; сценарий регистрации и публикации в этом CI-прогоне не выполняется. Для документа использована тестовая HTTPS-ссылка; содержимое внешнего файла не проверялось.
